## 🏛 Architecture & Code Showcase

This portfolio contains an interactive live code showcase illustrating Clean Architecture principles in enterprise .NET:

1. **`ProductsController.cs`**: ASP.NET Core Web API controller with Dependency Injection, asynchronous `ActionResult<T>` responses, Swagger annotations, and status code standards.
2. **`ProductRepository.cs`**: Generic Repository Pattern implementation utilizing Entity Framework Core, LINQ queries, and transaction management.
3. **`AppDbContext.cs`**: EF Core Database Context configuring `Fluent API` entity relationships, indexes, auditing fields, and Decimal precision.
4. **`sp_GetSalesReport.sql`**: High-performance SQL Server Stored Procedure with Common Table Expressions (CTE), aggregations, `TRY...CATCH` error handling, and `NOLOCK` optimizations.

## 💻 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18.0 or higher recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation & Run

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/Anand9899/Portfolio.git
   cd Portfolio
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Start the Development Server:**
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:5173` to view the website.

4. **Build for Production:**
   ```bash
   npm run build
   ```

5. **Preview Production Build:**
   ```bash
   npm run preview
   ```
